# أصول شاشات «إتقان» الترويجية — وديجة الديسكتوب وجولة الإضافة

وُلِّدت في ١٩ سبتمبر ٢٠٢٦ من صفحتَي التصوّر (وليستا لقطات من التطبيق الحي):
- `docs/widget-pebble-design-2026-09-19.html` — جولة ودجة الديسكتوب (عرض حي + ٩ حالات)
- `docs/extension-tour-mockup-2026-09-19.html` — جولة استخدام إضافة كروم (٧ خطوات)

**القاعدة**: أي تعديل مستقبلي على التصميم يتم في صفحتي التصوّر ثم تُعاد توليد هذه
المجلدات بالأداة نفسها — لا تُعدّل الصور يدويًا.

## المحتويات

| المجلد | المحتوى | الاستخدام |
|---|---|---|
| `scenes/` | ٩ مشاهد ديسكتوب (2000×1126، خلفية معتمة) | أقسام الموقع، العروض، المنشورات |
| `scenes-extension/` | ٧ مشاهد إضافة كروم (2000×1126، خلفية معتمة) | صفحة الإضافة، شروحات الاستخدام |
| `states/` | ٩ حالات للودجة وحدها (680×860، **خلفية شفافة**) | أنميشن الموقع: كل حالة طبقة مستقلة |

## أسماء الحالات الشفافة (states)

1. `w-pebble-idle` — الحصاة الخامدة (كاميرا)
2. `w-menu-start` — قائمة البدء بخيارَيها
3. `w-pebble-rec` — الحصاة الكحلية أثناء التسجيل (عدّاد + نبض)
4. `w-flash` — بطاقة لحظة الالتقاط (لقطة + دائرة + تراجع)
5. `w-strip` — شريط الأدوات الممتد رأسيًا (إنهاء/إلغاء/إيقاف/ميك + تلميح)
6. `w-paused` — الإيقاف المؤقت بشريحة «نقراتك لا تُصوَّر»
7. `w-confirm` — تأكيد الإلغاء بذكر الخسارة
8. `w-toast` — إشعار «وصل الدليل إلى مساحتك»
9. `w-pill` — حبّة عجلات التدريب (أول جولتين)

## أفكار الأنميشن في الموقع (states)

- تتابع الحالات بترتيب الأرقام أعلاه = قصة الجلسة كاملة (بدء ← التقاط ← شريط ← إنهاء).
- كل الصور بإطار موحّد 340×430 منطقيّ (والحبّة 380×240) والحصاة مثبّتة الركن
  السفلي الأيمن — ركّبها فوق بعضها بنفس الإحداثيات وبدّل `opacity` فتتشكل
  انتقالات سلسة بلا مطابقة يدويّة.
- المقياس مضاعف (2x) فيصلح للشاشات الحديثة مباشرة.

## إعادة التوليد (عند تعديل صفحات التصوّر)

من مجلد `%TEMP%\widget-mock`: عدّل `shots_desktop.json` أو `shots_ext.json` عند
الحاجة ثم:

```
python make_export.py <صفحة التصوّر> <shots.json> export.html
# ثم حلقة chrome --headless=new --force-device-scale-factor=2
#   --default-background-color=00000000 (للحالات الشفافة)
#   --screenshot=... "export.html?shot=<اسم>"
# الحالات الصغيرة تُصوَّر على نافذة 1000x900 ثم تُقصّ من الركن السفلي الأيمن
# بمقاس القماش (كروم بلا واجهة يقصّ النوافذ الأصغر من ~497px)
```
